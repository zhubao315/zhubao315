## 把方法做成系统，把生活记录成数据

我做 AI 与 Agent 工程、数字产品、知识工程与投资研究，也长期记录自己的健康与运动。

作品集里没有“领先”“颠覆”这类形容词，只有公开代码、可访问的站点、可复核的数字，以及每个项目主动写明的边界。18 个案例、6 个旗舰项目，全部标注来源类型与最后核验日期。

## 工作方式

1. **先定义问题，再选择工具。** 先确认边界、证据和验收方式，再决定要不要引入新的框架。
2. **可验证，比看起来聪明更重要。** 让结果能被复跑、被审计、被回滚；对数据缺失、证据不足和失败路径保持诚实。
3. **把经验沉淀成系统。** 一次性的 Prompt 是消耗品，可复用、可调用、可迭代的 Skill 才是资产。
4. **长期记录，持续复利。** 身体、知识和作品都需要时间尺度。可信的长期数据，比任何单点高光更有价值。
